# ERPForAll documentation

Three short guides cover installing, developing and deploying ERPForAll. A documentation website does not exist
yet; these files are the documentation.

- [Installation](install.md): prerequisites, building, creating the database, starting the server, the first
  sign-in, and installing an addon from a folder.
- [Development](development.md): repository layout, the crates, how a change flows, writing an addon, the web client,
  pull request rules.
- [Deployment](deployment.md): a release build, roles and configuration, running as a service (systemd, Docker),
  HTTPS behind a reverse proxy, upgrades, backups and rollback.

Contributing rules (licence, sign-off, build and test commands) are in [CONTRIBUTING.md](../CONTRIBUTING.md);
reporting a security problem is in [SECURITY.md](../SECURITY.md).
