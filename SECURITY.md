# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use the repository's Security tab and choose
"Report a vulnerability" (GitHub private vulnerability reporting). Include a description, the affected version or
commit, and steps to reproduce.

We will acknowledge a report and keep you informed of the fix. Please give us reasonable time to release a fix
before you disclose details publicly.

## Supported versions

ERPForAll is in early development. Fixes land on the `main` branch.
